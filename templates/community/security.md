# Security Policy

## Supported Versions

We support the following versions for security updates:

- The main branch (development)
- The latest release

Older releases are not supported. If you are using an older version, please upgrade to the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. Do not open a public issue.

**Preferred reporting route**: Use GitHub private vulnerability reporting. Navigate to the Security tab of this repository and select "Report a vulnerability".

{{CONTACT_FALLBACK}}

We take all security reports seriously. We will investigate and respond as soon as possible. We do not promise specific response timelines, but we will acknowledge receipt and keep you informed of progress.

## What to include in a report

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes or mitigations (optional)
