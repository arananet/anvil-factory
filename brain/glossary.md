# Glossary

- Work order: a single unit of work moving down the line.
- Station: one step with a manifest, inputs, outputs and a kind.
- Pipeline: an ordered list of stations, with optional parallel groups.
- Gate: a deterministic check with a pass or fail answer and a reason.
- Packet: the file handed to an agent station in a dry run.
- Envelope: the typed handoff record between stations in a run.
- Loopback: a step that returns work to an earlier station instead of approving it.
- Swimlane: the per station view of a run with status, time and artifacts.
