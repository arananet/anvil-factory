# Decision records

Numbered standing decisions for this project. Stations read the brain as context, so these records govern future work until a later decision supersedes one of them. New records take the next free number, following the format of the existing records.

- 0001, Composable stations: pipelines are composed from reusable stations, each defined once in stations/. Status: accepted.
- 0002, Headless Blender for modeled 3D assets: headless Blender with deterministic build scripts is a standing production tool for modeled 3D assets, scenes and renders. Adopted 2026-10-31.
- 0003, Evidence must exercise the production shape: run evidence for bundled or served deliverables must exercise the production shape, not only the source shape. Adopted 2026-10-31.
