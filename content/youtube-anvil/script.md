# ANVIL: an open source software factory

## Narration

### 1. Hook

Target timing: 0:00 to 0:10

The product on this page was designed and built by a software factory called ANVIL. Work enters as an intake and leaves as reviewed, approved output.

### 2. The line

Target timing: 0:10 to 0:33

Work comes in as a feature, an idea or an issue. Before any code is written, the spec is written. Then specialized stations do the work in a line, and no station approves its own work. For software, five reviewers check the work in parallel: spec, security, tests, architecture and design. A human approves before anything ships.

### 3. Verified memory

Target timing: 0:33 to 0:45

ANVIL also keeps a verified memory. A learning only enters that memory when its provenance ties back to a run record. Proposals that cannot be verified wait in quarantine.
