## Command classes used

- pip or pipx installed edge-tts (already present); apt installed ffmpeg and ffprobe (not present on the runner).
- edge-tts command line: text file in, mp3 out, voice en-US-ChristopherNeural.
- ffprobe: duration, stream and resolution measurement.
- ffmpeg: still image looped to a clip with filter_complex (crop, scale, pad, drawtext, apad, aresample), libx264 and aac encode, concat demuxer assembly, single frame extraction to png.
- Shell and python3 for arithmetic and file handling.

## Issues during production

- The first segment build used an input side duration limit and ffmpeg printed "Error while filtering: No space left on device" for four stills even though the disk had free space. The outputs from that run were discarded. The final segments were rebuilt with the duration limit on the output side, which ran with no errors, and the final file and frames come from that run.
- tools/video_checks.py counts S3 words over the whole Narration section including the "Target timing" lines and the block headings, so it reports 237 words for a script whose spoken text is 189 words. This is a checker or script structure question for the operator; script.md was not edited by this station.
